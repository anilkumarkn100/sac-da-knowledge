## Step Types Overview

| Step Type | Use Case | Notes |
|---|---|---|
| Copy | Move data between dimensions/versions | Most common |
| Advanced Formula | Complex calculations | Use TRACE() for debug |
| Allocation | Rule-based distribution | Needs driver data |
| Currency Conversion | FX conversion | Requires rate table |
| Embedded Data Action | Nest one DA inside another | |
| API Step (Multi-Action) | Call external HTTP API | Multi-action only |
| Version Management (Multi-Action) | Publish versions | Multi-action only |
| Data Locking (Multi-Action) | Lock/unlock slices | Multi-action only |
